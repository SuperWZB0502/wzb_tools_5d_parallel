# XY-Train 5D 并行可视化 · 实现设计

日期：2026-10-31。基于用户提供的第四版说明。原始说明保存为 original-design.txt。

实现核验更新：2026-11-02。

## 目标与边界

交付 tools/draw_parallel_card.html，单文件内嵌 CSS、JavaScript、SVG，离线打开，无网络请求、CDN、训练环境或服务依赖。按用户给定的两套 RankGenerator 模型计算，最多 4096 卡。此项目不连接原 XY-Train 仓库；源码语义以用户提供的说明为依据，不声称重新核对了私有源码或执行了训练。

## 本次优化决定（包含最新五项共享母线修订）

- 固定三栏：左侧配置，中间权重画布/通信组，右侧可固定详情。窄屏自然换行。白底、冷灰画布、深海蓝文字。Attention 统一黄色系（色相 46），MoE 统一蓝色系（色相 211）。五种通信域使用独立颜色，提供鲜明、色盲友好、矿物三套配色；同域框、连线、详情标记同色。阶段以实线、线段、虚线区分。系统中文字体，rank 数值使用等宽字体。
- 默认配置为 16 卡、TP=CP=DP=PP=EP=2、4 层，PP 分布预置 [2,2]，专家数为 8。修改总层数或 PP 时先自动均分，余数分配给后面的 stage；随后可手改。19/4→[4,5,5,5]，18/4→[4,4,5,5]。导入和示例中的手动分布保留。配置无效时立即清空当前结果和固定详情，约 200ms 防抖后重新验证。
- 基础配置与显示状态分离。阶段、stage 选择、缩放、卡分页、复制块选择不改变拓扑。模式扩展开启时强制 AllToAll，关闭后恢复上次选择。无专家时强制关闭扩展、要求 EP=1。
- 三个阶段为「正向」「反向」「梯度同步与参数更新」。反向只包括激活梯度传播；Attention 的 DP×CP 域、MoE 的专家副本域梯度同步都属于第三项。distributed_optimizer 关闭时第三项为梯度 AllReduce，开启时为梯度 ReduceScatter 与参数 AllGather，两条关系使用不同身份，均以第三阶段虚线显示。
- 点击锁定模块、通信高亮与右侧详情；固定后悬停其他 rank 不再改变信息或高亮。再次点击同一模块、画布空白、取消固定或 Escape 可退出。未固定时仍可悬停预览。每个模块的详情展开状态、成员页码和滚动位置分别保存。
- PP 按真实编号从上到下排列。各 stage 内卡统一横向，TP 变化最快、间距最小，其次 CP，最外层 DP。DP 框包含 CP，CP 包含 EP，EP 包含每卡 TP 范围；EP 坐标使用 combined % EP，每个框只包括当前 CP 坐标对应的 TP 卡。DP2/CP2/EP2→EP 编号 [0,1,0,1]；EP4→[0,1,2,3]。实际 EP 通信组仍按完整拓扑生成。点击框只高亮全部范围成员，不附带选中或标注首卡模块，再点同一标识退出。
- 删除「stage 窗口」控件；整张纵向画布可滚动，内部仅渲染视窗附近的展开 stage。stage 选择器保留分页，入口左侧标注「选择PP stage」。连续未选 stage 合并为紧凑圆角描边框，单行显示「PP x ~ PP y · 层范围 · 层数」，字体与展开 PP 均为 14px、650 字重。框按文字宽度计算，不再伸出长横线。点击可展开该范围。
- 总卡数/PP≤16 时，stage 内显示全部真实卡及 CP/DP 副本，隐藏复制块和横向卡分页；缩小时仍完整绘制视窗内选中 stage，不套用 128 卡截断，以落实「全部画出」的新要求。更大规模才保留 lcm(CP,EP) 周期的复制块；有多个重复块才显示控件。大规模横向卡页预算按全部选中 stage 数计算，滚动不改变页大小，交互渲染不超过 128 卡、256 模块。
- 原「定位」改为「查询」，输入框左侧标注「查询rank号」。查询会显式展开 stage，选择正确复制块和卡页，再滚到实际 rank。底部滚动位置先按画布边界夹取，保证目标卡不会在下一帧消失。隐藏 PP 邻居连到真实相邻 stage 所在的收起框；详情保留实际 rank 与层边界，绝不跳过 stage。
- SVG 在自己的滚动区内缩放，空白可拖动；点击画布或聚焦后按住 W/A/S/D 上/左/下/右连续平滑移动，Shift 加速；输入框打字不触发画布移动。键盘 Enter 与触屏点击均能固定模块详情。悬停模块预览连线，点击后固定；点击 rank 卡片汇总两类模块，列表与线同步筛选。
- PP 完全按 rank 生成，不依赖 Attention/MoE，前后真实相邻 stage 均可连接。按实际传输方向，从源卡左侧距底部 1/5（高度 4/5）连接目标卡左侧距顶部 1/5。收起邻居连接紧凑框靠近本卡的一侧；前向/反向实际源、目标保持准确。
- 集合通信按模块、实际域及组编号合并成共享横线；每个可见组成员只出一根支线，取消锚点向所有对端逐一发线。多个阶段/操作共用组母线，横线分段保留阶段线型，标注包含全部阶段与算子。实际完整成员与右侧关系不合并丢失。
- Attention 从底边、MoE 从顶边出线，共享间隙的上/下半区。TP 端点居中，EP/TP×EP、CP、DP/副本域每层将左端左移、右端右移 12px，内部成员端点对称渐变，使外层包住内层。横线不增加端外留边，两端竖线向内圆角拐弯后直接接入横线。仅一个可见成员时保留竖直支线、可见数量与说明，不虚构第二个端点。其他点对点路由按方向从对应边居中进出。
- 横线中央恢复通信域和算子说明。成员支线绕开其他标签，标签覆盖层在拱桥上方；剩余实际交叉使用自适应拱桥。PP 描述放在 stage 间隙。导出 SVG 保留所有母线、支线、行内标注和图例。
- 分页后锚点不可见时，只要该组还有可见成员，就保留共享母线并标记可见数/完整成员数。PP 仍需要当前可见 rank 端点，不伪造离屏端点。查询、阶段变化保留卡的可视位置。
- 无通信关系时只高亮锚点，不用基础通信组补亮其他 rank。范围选择单独控制范围高亮，不生成首卡模块选择。
- 通信组表只提供 TP、CP、PP、EP、DP、DP+CP、专家副本七类，完整总卡数计算，按组分页。组编号使用前缀积/mask 的独立坐标压缩顺序。TP×EP 只作为具体路由关系的实际通信域，不另作组表入口。
- PP 层边界的箭头与传输方向一致：前向 L9→L10，反向 L10→L9。超长专家与 head 索引约束在槽位/模块宽度内，不进入连线区域。
- Attention/MoE 名称置于色块左上方。新增 Attention head 总数输入：示例默认 16（4096 卡示例为 64），可由用户修改，需为正整数且能被 TP 整除。本卡 head 范围为 TP rank×(head 总数/TP) 起的连续区间。旧配置未提供 heads 时保留为空并明确提示，不凭并行卡数猜 head 数。
- Attention：整个参考框按 TP 横向分槽，仅本卡槽位填色并标注 h 起止。普通 MoE：完整专家参考框按 EP 横向分列、TP 纵向分行，本卡的归属矩形为 1/EP 宽、1/TP 高；EP2/TP2 对应左上、左下、右上、右下四个不同参数块。e 起止放在本地块内；过窄块适配文字。单个索引只显示一次。
- 扩展 MoE：完整参考框按 TP×EP 分成横向槽，槽索引为 ep×TP+tp，仅本卡所属槽填色，显示本地 e 起止索引。单个专家显示一个索引。每槽代表分配到该卡的完整本地专家，槽比例 1/(TP×EP) 不表示把专家权重切薄。大量槽只画必要边界，模块数量与专家数无关。
- 卡片标号完整写成 rank 0、rank 1 等；标号右侧放 2 行×6 列小表格，首行为「并行 PP DP EP CP TP」，第二行为「rank」及五个纯数字坐标。表头为可多选按钮，点「并行」全选，size=1 不可点击。以点击所在 rank 为查询锚点；联合域保留完整实际对端，TP×EP 可由 TP/EP 筛选，DP×CP 与专家副本同步可由 DP/CP 筛选，不截断集合通信。框的 rank 标号均居中，字号和字重与 PP 一致。
- 并行特性模块始终展示，顺序为 sequence_parallel、MOE分发、moe_tp_extend_ep、distributed_optimizer；各项下方显示当前切分/通信状态。分发默认 AllToAll，两个复选框互斥且至少一个选中；扩展时固定 AllToAll。
- 黄色/蓝色色相固定，PP 越靠后整体越深；同 stage 下不同 TP 分片、专家参数用亮度差区分。相同参数的副本颜色完全一致；身份判定使用精确键，不依赖颜色。
- 配置导入拒绝布尔值、数组等冒充数值的字段以及字符串形式的模式开关；成员翻页保留已展开的详情；载入示例重置旧的 rank 与画布滚动位置。
- 配置 JSON 导入/导出、SVG 下载与默认 16 卡、32 卡、三阶段、4096 卡示例均为本地操作。SVG 导出包含所有选中 stage（当前复制块与横向卡页），不受滚动渲染影响。输入 JSON 同样验证，禁止导入内容进入未转义 HTML。

## 核心接口

### 画布交互增强

- Attention / MoE 共用跨线算法。按圆角的实际可用直线区间检测交叉，避免固定 7/9px 排除距离遗漏短线和端点附近交叉；母线端部接缝向内保留 18px，外域支线跨越接缝附近时仍可生成可辨认的拱桥。桥层在所有线路之后绘制，索引背景和说明文字不被网格或连线盖住。
- h/e 索引在文字实际测量框外增加水平 3px、竖直 2px 的白色圆角背景，并限制在模块范围内，导出 SVG 保留。归属矩形及参数填色保持不变。
- 无固定选择时，鼠标移动到模块会生成该模块的真实通信线及详情；有固定选择时，悬停不切换任何卡片/通信信息。预览和固定共用组数据和布局。触屏按下及兼容鼠标焦点事件不触发预览重绘，避免吞掉触屏点击。
- 展开和收起 PP 行都提供范围标识按钮；展开/收起由独立加减按钮控制。范围选择高亮真实成员，隐藏 stage 的成员仍可从详情查询；不选择一个模块，也不生成该范围的模块通信。
- 通信母线和 PP 文本框是独立鼠标/键盘按钮。浮窗位于中央工作区内部，悬停显示、点击固定，展示实际域、组、各阶段算子、内容、目的、PP 相邻 rank/层边界及真实成员（每页 32）。浮窗固定状态与卡片固定状态独立；关闭不清除卡片。阶段切换和 PP 收起同步更新内容及当前可见成员数量。
- 固定浮窗按通信键持续查找当前 SVG 中的简述框并读取实时边界，不保存点击时的屏幕坐标。画布平移、WASD、页面滚动、缩放、侧栏/全屏布局及 SVG 重绘后均重新定位。简述框移出画布与屏幕的交集、被收起或切换到通信组表时，浮窗以 visibility 暂藏，保留固定内容和成员页；锚点重新可见后恢复。原有窗口边界避让保留，浮窗不溢出屏幕。
- WASD 使用按键状态和 requestAnimationFrame，以每秒 660px（Shift 2.2 倍）移动；短按小步移动，松键、失焦或进入输入框停止。滚动保持当前 SVG，只有可见虚拟 stage 集合变化才重绘，避免逐帧重建 SVG。重绘按模块、rank、域、PP 或通信标签身份恢复焦点，目标消失时回到画布。
- 两侧面板独立收起为 36px 窄条并可恢复。中央视图区增加原生全屏入口，单框/重叠双框图标切换；受限环境回退到视窗内全屏。全屏保留查询、阶段和画布控件，Esc 只先退出全屏，保留选择和固定浮窗。Ctrl＋滚轮以指针位置为中心连续缩放。

### rank 卡片与权重归属修订

- rank 标题、卡片边缘及内部空白支持单击选定，默认恢复全部通信域并汇总 Attention / MoE 的实际通信关系；正向、反向、梯度同步阶段保持用户原有勾选。模块与表头按钮继续按各自职责响应，不触发卡片选择。再次单击同一 rank 或画布空白退出，固定时悬停其他模块不改变详情或高亮。
- rank 卡片底框作为独立键盘按钮，支持 Enter / 空格，使用 aria-pressed 标示选择状态；不套叠模块和表头按钮。卡片点击不触发空白拖动。极窄分片的边界与角标按局部宽高缩小，保留中间的实际权重填色。
- Attention / MoE 的非本卡参考区域统一为不透明灰色 #e3e8ed。本卡参数填色规则保持相同参数同色；额外增加深黄色或深蓝色内描边和四角标记，所有描边裁切于实际持有矩形内部，避免影响邻接分片的颜色。
- 普通 MoE 的专家编号位于整个 EP 横向列中央，不随 TP 纵向行移动；同 EP、不同 TP 卡显示相同专家范围，仍以本卡描边标示实际权重行。扩展模式的专家归属是 TP×EP 横向槽位，编号仍随真实槽位显示。单专家只显示一个 e 索引。

## 重要验收

32 卡：DP=4，r0 的 Attention 副本 [0,2,4,6,8,10,12,14]，MoE 副本 [0,8]，PP [0,16]；两种模式专家区间正确；AllGather 路由域 [0..7]。
三阶段：[3,5,4] 默认仅 stage 0/2，r0 的 PP 下一跳必须是真实 stage 1，不越级连接 stage 2。
4096 卡：DP=32，专家副本=8，span=8，重复块=8；默认 128 卡/256 模块。展开全部后分页；TP=4096、PP=4096、全收起、全取消阶段、非法整数和层数不一致都可用。

## 验证边界

通过可重复执行的 Node 测试核对模型，再通过浏览器检查交互、桌面/窄屏、导入导出和离线状态；浏览器可用性若受环境限制须如实报告。
