# XY-Train 5D Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; execute inline and verify the final artifact.

**Goal:** 用户给定设计的离线交互 HTML。
**Architecture:** 单 HTML 内分为纯拓扑模型、关系模型、SVG/表格 UI；测试从 HTML 提取真实模型执行。
**Tech Stack:** 原生 HTML/CSS/JavaScript/SVG、Node 内置 test/assert。
**Spec:** design.md 与 original-design.txt。

## Global Constraints
- 总卡数 1～4096；PP 自动均分后可手填；每卡固定 1～2 模块；大规模最多 128 可见卡，每 stage≤16 时完整显示视窗中的卡。
- 七类组；CP/DP 共用 EP 卡空间；真实 rank、stage、通信域不受折叠影响。
- 离线单文件；不发布站点、不操作私有训练代码。

## Review Focus
- 无效输入后不能保留旧图。
- 无专家和扩展切换必须同步选项。
- 隐藏 stage 的 PP 不越级。
- 多阶段筛选后固定详情与连线一致。
- 极大 TP/PP、分页与定位无越界。
