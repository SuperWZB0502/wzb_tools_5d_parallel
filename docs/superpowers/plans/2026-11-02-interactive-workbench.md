# 5D 画布交互增强实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 完成用户八项修订，统一 Attention/MoE 连线、预览与固定，提供清晰标签、PP 范围选择、详情浮窗、连续移动、侧栏收缩及全屏缩放。

**Architecture:** 延续离线单 HTML、SVG 拓扑和事件委托。绘制数据与可见视窗分开，悬停和固定共用通信生成流程，固定状态只限制预览切换；通信浮窗有独立固定状态。移动使用动画帧和按键状态，滚动只在虚拟 stage 集合变化时重绘。原生全屏优先，无法进入时采用浏览器视窗内全屏。

**Tech Stack:** 原生 JavaScript、CSS、SVG；Node 模型测试、Edge Playwright 交互验证。

**Spec:** 本轮用户八项明确要求及 `docs/design.md`；保留现有离线、权重归属和真实通信组规则。

## 全局约束
- 无外部资源、服务或训练依赖，直接打开 HTML 可用。
- 固定后悬停不改变卡片、详情或连线；再次单击同一对象/画布空白退出。
- 标签背景仅略大于文字，保留真实切分边界和参数颜色。
- 默认保留三阶段独立勾选；PP 范围选择只高亮范围，不选择一个模块。
- 全屏中保留阶段/查询/画布工具，Esc 退出全屏优先于清除选择；Ctrl+滚轮围绕指针缩放。

## Review Focus
- 未固定预览触发重排后，鼠标仍应能顺畅移到其他模块，固定后绝不被误换。
- 全屏 Esc 与选择 Esc 不互相吞掉；图标与实际全屏状态同步。
- 浮窗元素接收点击，不能被 SVG pointer-events 或拖动捕获吞掉。
- 连线桥必须位于实际交叉处，不能只增加装饰性圆弧或被重复线覆盖。
- 按键松开/切到输入框/窗口失焦时不能继续滑动；大规模滚动仍按真实 stage 虚拟化。
