# 调度画布与层分布表实现计划

**目标：** 统一显示流水线阶段，完整显示至少 8 个物理 stage，增加调度图导航，按 chunk 使用同色深浅，并以表格展示层数。

**实现：** 保留单 HTML 和现有调度依赖模型。SVG 继续按视窗绘制；左侧表格固定列、顶部固定阶段名称和时间刻度，下载 SVG 保留完整内容。使用独立调度图全屏容器，避免影响权重图已有全屏和键盘事件。

**阶段口径：** 整条流水线最后一个 stage 第一次前向开始前为 warmup，最后一次前向结束后为 cooldown，中间为 1F1B；这是全图填充/排空口径，不代表每个 stage 的本地 warmup。GPipe 仅显示全部前向/全部反向，PP=1 时无流水线填充阶段。边界只绘制两条全高线，不在每行重复阶段文字。

**颜色：** PP 前向浅绿、反向深绿；VPP 0 前向浅黄、反向亮黄，VPP 1 前向浅蓝、反向亮蓝。更多 chunk 使用其他色相的深浅配对。F/B 与 chunk 文字仍保留以辅助辨认。

**表格：** PP stage 列下逐行显示 PP0、总层数及峰值待反向块。层分布列在 VPP 下细分为 VPP 0、VPP 1 等，PP stage 表头合并两行。较多 chunk 按列分页查看，下载 SVG 包含全部 chunk 列。

**选中顺序：** 选中微批后为其全部 F/B/chunk 任务添加执行顺序箭头，颜色与选中边框相同。向下连接用源块下边居中到目标左边居中，向上连接用源块右边居中到目标下边居中；同一行使用绕行曲线。箭头不接收鼠标事件，取消选择后清除，SVG 导出保留选择与箭头。
